# Como publicar a v1.0.0

1. GitHub: substitua TODOS os arquivos do repositório pelos desta pasta.
2. Supabase → SQL Editor: rode `SQL-PARA-RODAR-AGORA.sql` (se ainda não rodou).
3. Notificações na barra do celular: siga o arquivo **PUSH-CONFIGURAR.md**,
   que foi entregue SEPARADO (tem chaves secretas — não coloque no GitHub).
4. Abra o app 2 vezes no celular. O rodapé do menu deve mostrar v1.0.0.
